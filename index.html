Model transparency

UV dose is calculated from irradiance × exposure time. Turbidity reduces effective UV transmittance, so a dirty source can require lower flow or more UV exposure. Treatment stages use simplified first-order removal kinetics. The metal value is an electrochemical signal index, not a laboratory concentration.

Prototype only: real deployment needs calibrated sensors, measured media coefficients, pump/filter curves, UV validation and laboratory testing.
